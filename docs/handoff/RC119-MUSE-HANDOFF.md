# RC119 TMDB 片单候选交接

2026-11-10。基于 GitHub RC118 候选提交 36761b3。此轮按用户要求只发布 GitHub，MiniPC 局域网 RC118 和 Oracle 候选入口维持各自版本。

- 首页顶栏新增 TMDB，默认本周趋势，可切换电影、剧集。沿用现有海报网格、详情、找源与导航逻辑。
- 用户在设备设置填自己的 TMDB Key，凭据继续存设备。片单读取 TMDB v3，卡片保留媒体类型与 TMDB ID，详情显示 TMDB 评分和简介。图片使用 TMDB CDN，归属声明和标志随页面发布。
- 浏览器夹具验证三分类、未填 Key 引导、过滤人物、电影与剧集相同数字 ID 时各自显示、详情简介和评分。真实 TMDB 凭据、电视遥控、原生播放仍需用户验收。
- 回退时重新导入 rc118.json。未涉及原生 JAR 或本地手机键盘试用功能。
