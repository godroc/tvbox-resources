# Muse 开发交接 · RC119-r3

日期 2026-11-10。公开基线为 RC119-r3，功能提交 `86107e7`，Pages 发布重试提交 `b1369ed`。静态资产目录 `docs/webhome/rc119-r3-db6510976483/`。GitHub 的 `rc119-r3.json` 是公开候选入口，共 158 个站点。公开候选在三端使用同一份静态资产，各端配置仅替换 WebHome 的首页地址。

## 已有功能与验证

- TMDB 推荐页有本周趋势、近 90 天新片、在播剧集和高分佳片。电影及剧集支持地区、类型、年份、评分与排序筛选，列表复用分页海报墙。
- TMDB 中转、详情找源、直播和红果保留 r3 的行为。模拟 SDK 已验证推荐、分页、筛选、详情和中转错误分支。电视遥控和实际数据仍需验收。
- 私密资源另有局域网试用分支。已验证解锁、退出私密页恢复公开首页、锁定撤销，以及私密页定期续期。试用版由局域网服务执行 Python，部分上游请求不稳定，封面与真实源起播未验收。该试用实现用于复现与回归。

## Muse 接手目标

1. 用户要求从 WebHome 的私密入口进入，选中资源后才向 MiniPC 取对应 Python Spider，由 App 运行。
2. 私密源必须独立于主配置 `sites[]`、原生站点列表和现有搜索。浏览和搜索入口仅在解锁后的私密页面内。
3. 先验证 WebHTV 的原生桥接能否创建未注册的临时 Python Spider，调用分类、搜索、详情、图片代理与播放，并在锁定后释放。现有 `fm.vod` 依赖配置中的站点 key，当前 SDK 文档里未找到临时加载接口。若无现成接口，先用无敏感内容的样例验证 App 桥接或受支持的插件方案，再接真实源。
4. 验收覆盖未解锁、进入后按需下载、公开搜索无私密结果、遥控返回首页、私密页续期和锁定清理。分别在目标 WebHTV 和 OK影视版本上验证。通过后再决定是否替换局域网试用实现。

内部候选源码和运维说明保存在两台服务器的非网站目录。真实源文件和运行数据由 MiniPC 本地持有。
